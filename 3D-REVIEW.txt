3D: НЕЗАВИСИМОЕ РЕВЬЮ
24.10.2026. Foundry v12 / cyberpunk-red-core, локальный Three r172.

Исправления
1. Отложенный click больше не выбирает удаленную сущность после перестройки
   сцены. Удаленный во время pointer capture объект не остается целью ПКМ.
   Hover и tooltip очищаются при исчезновении объекта; подсказка обновляется
   при изменении данных того же ref.
2. Включение prefers-reduced-motion во время уже запущенной атаки удаляет
   эффект и завершает цикл кадров. Listener отключается через AbortController.
3. Общий кеш моделей живет до закрытия последней 3D-сцены. Закрытие одного
   из двух окон не освобождает геометрии, используемые вторым. Dispose идемпотентен.
4. Отступ между соседними ветками учитывает фактическое число демонов,
   включая больше трех демонов. Непрозрачные полы и depth test сохранены.
5. Three.WebGLRenderer.setSize в локальной r172 безусловно присваивает
   canvas.width/height. Теперь это вызывается только при изменении размера
   viewport, а не на каждом кадре камеры/FX. Метрика inspect.bufferResizes
   позволяет проверить отсутствие повторных выделений буфера при движении.

Контракт кастомных визуалов
entity.visual = {model, color, animation}.
model: точный стабильный ключ из MODEL_KEYS (32 модели).
color: #rrggbb, необязательный; иначе цвет владельца/сущности/роли.
animation: auto, none, sword, banhammer, deckkrash, hellbolt, nervescrub,
poisonflatline, superglue, vrizzbolt. Это профиль FX, без фонового idle motion.
auto берет выбранную visual.model либо штатную семантику программы.
Неизвестные поля безопасно нормализуются; произвольные строки не становятся
кодом, CSS или импортируемым путем. Визуал не меняет имя или стабильный ref.
Одинаковые 32 модели доступны программам, Black ICE и демонам.
Событие атаки может нести visual: это сохраняет профиль после штатного
autoderez программы. Визуал владельца не подменяет визуал исчезнувшей программы.
FX сохраняет зафиксированные endpoints при перестройке мини-программ после
autoderez (включая смену 9->8 и изменение координат раскладки). Исчезновение
owner/target, fog или смена их этажа отменяет FX, скрытые endpoint не остаются.

Проверки
node tools/models-test.mjs: 32 уникальных нормализованных модели; кеш;
96 сочетаний custom model/kind; fog с бросающими getters; отделение веток;
подсчет освобождения ресурсов при двух потребителях кеша.
node tools/presentation-test.mjs: 54 screen-space pan случая с различными
yaw/tilt/zoom, реальный владелец программ, цвет владельца/кастомный цвет.
node tools/attack-effects-test.mjs: 9 тестов; восемь Attacker, fallback,
попадание/промах, cap=4, 24 частицы, finite endpoints, одноразовый dispose.
node tools/webgl-test.mjs: настоящий Chrome WebGL/SwiftShader. Шейдеры,
opaque/depth, callbacks, камера, отсутствие idle кадров, context restore,
сохранение canvas при рендере родителя, обычный redraw во время атаки,
штатный autoderez, удаление hovered/queued select, custom BI/demon/program,
отсутствие мутаций VM от FX, динамический reduced motion, fog очистка.
Фаза FX проверяется детерминированными часами: setTimeout не гарантирует
пробуждение до момента impact под нагрузкой.

Замеры одного офлайн стенда, 100 этажей / 300 моделей / 8 обновлений:
до проверки размеров буфера: CPU build median 39.9 мс, полный кадр c gl.finish
70.6 мс, максимум (nearest-rank P95 из 8) 196.6 мс.
после: CPU build median 19.2 мс, полный кадр 59.3 мс, максимум 235.0 мс.
В обоих случаях 8 draw calls, 3 видимых HUD. Параллельная нагрузка и GC
не контролируются, эти замеры не доказывают конкретный коэффициент ускорения.
Повторный размер GPU буфера при неизменном viewport устранен регрессией.
5 циклов открытия/закрытия после изменения: 139.8-154.9 мс; 0 observers,
0 оставшихся DOM-сцен; консоль без ошибок. Обычная сцена: 12 моделей,
26 draw calls. PNG стенда просмотрен: карточки читаемы, полы непрозрачные,
модели над поверхностью, hover не меняет расположение.

Ограничения
Это Node и отдельный Chrome fixture, а не проверка игровой сессии Foundry.
Живые Actors/Items/settings не изменялись. Нужна ручная проверка в резервном
мире: GM и игрок, кастомная программа после переименования и autoderez,
две 3D-сцены с закрытием одной, исчезновение/скрытие цели во время атаки,
ПКМ-pan после yaw/tilt, изменение размера окна, включение reduced motion.
Ожидается сохранение боевых результатов штатного pipeline: FX не наносят урон.
