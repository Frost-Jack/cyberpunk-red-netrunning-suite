Новый редактор контента
Кнопка file-pen в панели GM. Program создаётся native Item program,
Black ICE/Demon native Actor blackIce/demon; не выдуманы Item types.
Создание с нуля/из world sample, load/save/copy/import/export; stable definition
ID и snapshot в document.flags. На Save не создаются документы и не меняются
существующие экземпляры/персонажи. Явная Create создаёт один world document,
не устанавливает Item в персонажа. Дальнейшее редактирование библиотечного
определения не обновляет уже созданные документы; bulk update не добавлен.
Кастомный ICE/Demon доступен в native architecture picker; inline snapshot
переживает export/reimport и удаление записи библиотеки. Native source
class/имя/статы используются при создании образца из переименованного документа.

Поддерживаются поля name/image/description/stats/class, подмножество целей
native class, dice damage без JavaScript/actor references, цена/слоты,
activation cost1..10, usage round/run. Лимиты по отдельной Item copy;
отмена возвращает точную стоимость. Восемь FX профилей/auto/none,
32 штатных моделей плюс explicit unknown fallback, цвет либо owner color.
Actor/Token изображения сохранены. GM явно применяет whitelist runner
эффектов; destroy на0REZ учитывает stable source. Manual descriptions
ничего сами не исполняют. Статы/условия, которые не поддержаны declarative
schema, сохраняются текстом и разрешаются GM; произвольного JS/eval нет.
Импорт ограничен размером/схемой, отбрасывает _id/ownership/macros/AE.

UX
Причина недоступности показана на кнопке: disconnected, deck disabled,
нет действий/цели, used copy, wrong floor context. Стоимость custom программы
видна. Player не запускает известное недоступное действие ради уведомления;
GM сохраняет Shift override. Огнём и disabled status можно управлять
по отдельности; HP/REZ остаются явными GM операциями. Окно редактора resizable,
scroll сохраняется, во время записи поля блокируются. Справочник остаётся
списком с поиском. Hover-scale/blur/постоянные новые анимации не добавлены.

Оставшиеся ограничения
P1: raw module socket не удостоверяет фактического отправителя. userId/gmId
metadata и dedup не являются аутентификацией против злонамеренного клиента.
P1: world settings читаются клиентом. Fog и FX защищают UI, не тайны от console.
Нужен отдельный архитектурный дизайн хранения/авторитетного транспорта для
защиты от adversarial player; текущие тесты не выдают это за решённую задачу.
Нативные функции пока требуют ручного GM разрешения ряда drain/status,
Kraken/Wisp/Skunk, unsafe Jack Out effects, reset REZ/позиций с учетом Virus,
Rock Lobster expanded actions, физических distance/walls/access/Breacher/FBC
условий и Lotos external hardware. Не все книги проверены постранично.
Legacy документы без managed marker сохраняются, могут требовать ручной
чистки после проверки происхождения. Автомиграция права удаления не назначает.

Удаление документов после native Delete тоже обрабатывается: primary GM
проверяет фактическое отсутствие документа, очищает exact architecture refs,
roster/mirrors/attachments/pending tests и только managed backing Actor.
Surviving Black ICE Item штатно выключается даже без экипированной деки.
2D hover/target callback проверяет актуальную разрешённую VM; действительный
выбор программы при обычном rerender сохраняется. Эти случаи покрыты
security24, canvas14 и rules41.
