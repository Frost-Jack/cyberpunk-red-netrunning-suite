СВЯЗЬ С СИСТЕМОЙ

Активная дека: Actor.getEquippedCyberdeck(). Установленные предметы:
system.installedItems.list и Container.getInstalledItems(). Список ID является
источником истины; лежащее отдельно оборудование и другая дека бонусов не дают.
Копия программы идентифицируется Item.id, состояние: system.isRezzed,
system.rez.value/max, system.class, system.size, system.damage.standard/blackIce.
Переносимые эффекты программ создаёт/переключает штатная система через
deck.rezProgram()/derezProgram(); модуль не создаёт вторые AE для тех же бонусов.
0 REZ не считается действующей защитой даже при отсутствующем defeated mirror.
Destroyed хранится как блокировка Item в session, чтобы сохранить копию и ID.
validateEquipmentLoadout(...,{excludedProgramIds}) позволяет не учитывать слоты
уничтоженных копий при проверке восстановленного/действующего набора.

Проверенные файлы системы:
modules/actor/cpr-actor.js: getEquippedCyberdeck;
modules/item/mixins/cpr-container.js: getInstalledItems;
modules/item/types/cpr-cyberdeck.js: rezProgram, derezProgram;
modules/datamodels/item/program-datamodel.js;
modules/datamodels/item/cyberware-datamodel.js: isInstalledInActor;
modules/datamodels/item/mixins/installable-schema.js: size, installedIn;
modules/datamodels/item/armor-datamodel.js: equipped, SP, penalty.
У Program нет Container/Upgradable mixin. Поэтому адресованное конкретной
программе Invented Upgrade связывается явным module flag, а не подбором имени.

ТОЧНОЕ РАСПОЗНАВАНИЕ

Предмет: flags.cyberpunk-red-netrunning-suite.equipmentKey либо точный ключ/
EN/RU alias каталога после нормализации регистра, пробелов и пунктуации.
Программа: flags.cyberpunk-red-netrunning-suite.programKey либо точный alias.
Поиск по подстроке и approximate matching не применяются. Переименованная
программа с programKey продолжает получать нужное правило оборудования.
customContent без явного equipmentKey/programKey не наследует стандартный
эффект от совпадения названия с Armor, Killer, Insulated Wiring и т.п.

ЯВНАЯ ПРИВЯЗКА INVENTED UPGRADES

Все flags ниже находятся в flags.cyberpunk-red-netrunning-suite.
Function Driver: на Cyberdeck upgradeKey="functionDriver" или установленный
ItemUpgrade с equipmentKey="functionDriver"; на той же Cyberdeck
functionDriverProgramId="точный Item.id" выбранной установленной программы.
Только non-Black ICE размера system.size=1 допустима для этого эффекта.
Netsuit Insulation: upgradeKey="netsuitInsulation" на надетой Armor либо
установленный в эту Armor ItemUpgrade с equipmentKey="netsuitInsulation".
Super Slide: upgradeKey="superSlide" на конкретном Speedy Gonzalvez/Worm Item.
Точные ID/flags сохраняются как данные предмета. Этот аудит не менял живые
предметы пользователя. Нет отдельного автоматического выбора получателя
Function Driver и нет созданных копий программ. Цена/DV/доступность изобретённого
улучшения, работа Tech и корректность исходного предмета остаются решением GM.

FBC SHARED HARDWARE

Создать/использовать native cyberware FBC Integrated Bodyweight Coating,
установленное в Actor (isInstalledInActor). Hardware устанавливается внутрь
его system.installedItems.list. Для integrated deck проверяются предки
cyberware контейнеров. Shared Hardware работает для этой деки и сохраняется
при CyberConductor switch; отдельный Hardware другой деки не разделяется.
Несколько coating складывают вместимость по 2. Это явное исключение источника,
не разрешение произвольно делить оборудование между любыми деками.

УСЛОВИЯ GM И ГРАНИЦЫ АВТОМАТИЗАЦИИ

Расстояние/стены/access point, DNA биометрия, FBC eligibility, покупка, работа
Tech, часы установки, внешнее Hardware Lotos и физические EMP, прошедшие через
чужой модуль, не выводятся из имени предмета и не заявлены автоматически решёнными.
Training Deck + Range Upgrade: Midnight 3 прямо требует 2 м для подключения
и поддержания связи; Core 208 разрешает Range Upgrade подключаться с 8 м.
Опубликованного официального разъяснения именно этой комбинации не найдено.
Текущий технический расчёт остаётся 8 м, но profile.rangeRequiresGM=true
обозначает спор приоритета правил: это не заявлено однозначным RAW решением.
У самой Training нет Hardware slots; такая комбинация возможна через законный
дополнительный слот, например надетый Bodyweight Suit.
Пользовательские targets ограничены подмножеством допустимых целей native
класса: anti-personnel против runner, anti-program против program/ICE/demon.
Произвольные атаки между классами требуют ручного разрешения GM; описание
пользовательского эффекта само по себе не меняет семантику native roll pipeline.
Armour SP/penalty и штатные program AE обслуживает система, а не второй AE Suite.
Breaking Your Stuff! 7 содержит опциональные Cyberdeck malfunctions, No Place
Like Home 5 расширяет Maker для Netrunner в upgraded Server Room. Это отдельные
подсистемы с состоянием HQ/maintenance, не постоянные бесплатные боевые бонусы.
Going Quiet остаётся отдельным официальным опциональным набором, не базовым RAW.
